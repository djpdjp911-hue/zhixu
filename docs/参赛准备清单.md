## 评分对应

| 维度（权重） | 作品对应 |
|---|---|
| AI 技术深度 35% | 大模型集成（Prompt 分段约束、结构化输出校验）；Agent（规划、工具调用、自主决策与兜底）；RAG（可追溯分块、混合检索、稳定引用）；多模态（图片识别、语音）；AI 安全（注入扫描、逐句核验、拒答与兜底）；MCP / Function Calling（共用工具定义） |
| 创新性 25% | 证据闭环 Agent；AI 出题原文逐字校验；费曼复述评估驱动间隔复习；学习资料经 MCP 开放给外部 AI |
| 前端工程 10% | TS strict + erasableSyntaxOnly；Context 状态中心与组件拆分；PDF.js 动态导入、按帧合并流式渲染 |
| 实用性 10% | 无密钥可用的完整学习闭环；免费国产模型即可开启 AI；备份与恢复 |
| 用户体验 10% | 流式渲染、思考状态可视化、失败重试与降级出口、键盘可达、手机适配 |
| 社会价值 10% | 降低查证成本、透明的自主学习过程、可切换免费或本地模型降低部署成本 |

一等奖由评审及同组作品水平决定。此清单用于提高完成度，不构成获奖承诺。
