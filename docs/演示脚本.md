# 知序演示脚本（建议 6 分 30 秒）

本稿为正式录屏准备。当前缺真实 API，不能把原文检索描述成大模型生成。正式提交前必须补录真实 AI 操作，并使用普通话讲解、MP4、至少 1920x1080。

| 时间 | 操作 | 讲解重点 |
|---|---|---|
| 0:00-0:35 | 学习工作台 | 项目名称、目标人群、资料多但理解碎片化的问题 |
| 0:35-1:15 | 导入自己课程的 PDF/文本 | 本机解析，保留页码；原始资料与章节，不只是上传动画 |
| 1:15-2:25 | 真实 Gemini 问答与执行记录 | 模型如何选择检索工具，找到证据，生成带编号的回答；展示真实执行过程 |
| 2:25-3:10 | 点击引用、完整上下文 | 证据回溯，检索分数不是正确概率；回答引用需人工语义核对 |
| 3:10-3:40 | 资料外问题与异常 | 证据不足时拒答；服务限流给出提示而不伪造回答 |
| 3:40-4:10 | 知识脉络 | 文档结构图可交互，不宣称为模型推理出的概念关系 |
| 4:10-5:00 | 完成学习诊断 | 展示真实作答、原文答案和错题反馈；规则练习的适用边界 |
| 5:00-5:35 | 复习任务 | 根据错题次日安排，调整日期、回到资料、完成任务 |
| 5:35-6:10 | 技术与评测 | 分块、BM25、可选向量RRF、工具白名单；展示实测结果及失败样例 |
| 6:10-6:30 | 价值与总结 | 证据、验证与行动的闭环；团队实际工作、真实试用反馈和后续计划 |

## 开发版旁白原则

若暂未接入 API，视频必须直接标注“开发版 / 原文检索模式 / 模型尚未联调”，并将 1:15-2:25 改为“检索及证据定位”。这样的开发版视频可用于内部讨论，不能替代包含真实 AI 技术亮点的最终参赛视频。

## 录制前

- 使用独立浏览器数据，导入经过授权的演示资料。
- 调大页面文字，保证 1080p 下清晰。
- 禁止出现 .dev.vars、API 密钥、真实用户隐私及系统通知。
- 展示来自实际运行的执行记录，不后期伪造工具成功状态。
- 计时 5-8 分钟，确保旁白同步，不用夸张效果承诺补足缺失能力。
