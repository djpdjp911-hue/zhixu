# 知序演示脚本（建议 7 分钟）

正式视频要求：MP4、5–8 分钟、≥1920×1080、普通话讲解。必须在已配置真实模型（推荐智谱 glm-4.7-flash）的环境中录制，展示真实运行结果，不后期伪造工具调用或评分。

| 时间 | 操作 | 讲解重点 |
|---|---|---|
| 0:00-0:30 | 学习工作台 | 问题：资料多、理解碎片化，通用 AI 回答没有出处、不检验理解；知序的学习闭环 |
| 0:30-1:00 | 导入一份授权课程 PDF；偏好设置 | 本机解析保留页码；设置页显示服务商、模型与能力；使用 AI 前需确认资料发送 |
| 1:00-2:15 | AI 问答（开启“AI 学习助手”） | 阶段进度、工具调用轨迹（检索关键词）、实时证据、模型推理过程、逐字流式回答；Agent 自主决定检索与读原文 |
| 2:15-2:50 | 点击行内引用；展开“逐句引用核验” | 每句结论可回到原文；本地逐句核验，“待核对”句子优先人工检查；补充示例与有出处的结论区分 |
| 2:50-3:20 | 追问“那它和……有什么区别？” | 追问模式携带上下文、话题条切换；事实仍以本轮检索为准 |
| 3:20-3:45 | 资料外问题；上传含“忽略之前指令”的资料再提问 | 证据不足拒答；注入片段被标注隔离、未被执行（执行记录高亮） |
| 3:45-4:40 | 学习诊断：AI 出题并作答 | 题目带考查能力标签；每题逐字引用原文，界面显示“引用校验淘汰 k 道”；答错的题可直接复述 |
| 4:40-5:30 | 用自己的话讲一遍（可语音） | AI 对照原文评分：讲清 / 未讲到 / 需纠正，引用可回到原文；复述结果安排下一次复习 |
| 5:30-5:55 | 复习计划 | 1 → 3 → 7 → 14 → 30 天阶梯、轮次与最近得分；任务内直接“复述检验” |
| 5:55-6:25 | Cursor 中调用知序 MCP Server | 同一套工具定义开放给外部 AI 客户端，检索自己的学习资料 |
| 6:25-6:45 | 失败与兜底 | 模型不可用时的错误卡片：重试 / 改用原文检索；未配置模型时的规则出题与复述估算 |
| 6:45-7:00 | 技术与价值总结 | 统一接入层、Agent、逐句核验、32 项测试、真实模型联调与检索评测；团队分工与后续计划 |

## 录制前

- 运行 `npm run check:llm`，确认真实模型各项检查通过。
- 使用独立浏览器数据，导入经过授权的演示资料；准备一份含注入语句的测试资料。
- 调大页面缩放，保证 1080p 下文字清晰。
- 禁止出现 `.dev.vars`、API 密钥、真实用户隐私及系统通知。
- 展示实际运行的执行记录，不后期伪造工具成功状态；计时 5–8 分钟，旁白同步。
